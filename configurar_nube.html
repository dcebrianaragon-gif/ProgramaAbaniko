Nube compartida

Esta pantalla deja preparada la aplicación para varios ordenadores usando Supabase como copia central compartida.

Estado actual

La nube es opcional. Si no la configuras, la app sigue funcionando en local.

Qué tienes que tocar

La configuración real se hace una sola vez en el archivo local de la app.

1. ArchivoLa URL ya está puesta. Solo falta pegar tu anonKey real en supabase-config.js.
2. Base de datosEjecuta supabase-setup.sql en Supabase para crear la tabla.
3. SincronizaciónUsa este panel para probar la subida y la descarga.

Cómo funciona esta nube

Explicado de forma sencilla para que se entienda qué se ha hecho.

Guardado localLa app sigue guardando en el navegador para que no se rompa nada ni dependa siempre de internet.
Copia centralCuando activas Supabase, la app puede subir una copia completa del estado a una tabla remota.
Lectura desde otros equiposLos demás ordenadores pueden descargar esa copia al abrir la app o al sincronizar.
Uso realSirve para compartir profesores, alumnos, jornadas y accesos entre equipos sin depender de un solo navegador.
Límite actualLa sincronización está pensada para una app ligera. Si dos equipos editan exactamente lo mismo a la vez, puede prevalecer la última sincronización.
