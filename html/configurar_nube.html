La app puede guardar en este equipo y tambien sincronizar con Google Sheets para compartir la informacion entre dispositivos y usarla online.

Base local

Guarda en el navegador y, si abres el servidor local, tambien en data/programa-abaniko.json.

Google Sheets

La web ya se conecta sola a Google Sheets con la URL publicada. Este bloque solo hace falta si quieres cambiarla manualmente.

La URL actual ya queda fija en la web publicada. Solo cambia este campo si quieres sustituirla por otra implementacion /exec.

Como activar Google Sheets

Pasos rapidos para crear el backend compartido.

1. Crea una hojaAbre Google Sheets y crea una hoja nueva para Programa Abaniko.
2. Apps ScriptExtensiones > Apps Script, pega tools/google-sheets-backend.gs y guarda.
3. DespliegaImplementar > Nueva implementacion > Aplicacion web. Ejecutar como tu usuario y acceso para cualquiera con el enlace.
4. Copia la URLPega aqui la URL que acaba en /exec y pulsa Guardar conexion.
